品牌與圖示

產品名 loopbee · 標誌與應用圖示都是這隻蜜蜂 · 常數只在 internal/brand 與 ui/brand.js 一處
介面標誌
蜜蜂線稿，與連線上飛的是同一隻；單色，跟隨文字色，用於標題列與空狀態
應用圖示 · 淺色
圓角方塊 + 彩色蜜蜂；Dock、通知、安裝包
應用圖示 · 深色
同一隻蜜蜂；深色底，翅膀改用淺灰
系統匣／選單列
單色 template 圖示；運行中只在右上加一個小圓點，不做逐格動畫

規則

觸發
只有 status 為 running／cancelling 才有連線動畫；queued、waiting、interrupted 是靜態姿態（停駐／失聯）。動畫完全由狀態代碼驅動，不由事件頻率驅動。
數量
每個運行中的 Run 最多一隻蜜蜂；同時運行上限 2，所以一個畫面最多 2 隻。Runs 列表與今日頁不放蜜蜂，只保留 ● 脈動。
位置
蜜蜂在「進入目前步驟的那條連線」上；步驟前進時，上一條連線轉為實線（完成），新連線開始流動。回圈時蜜蜂沿回圈弧線逆向飛回一次（1.2 秒，只在輪次切換時）。
時序
fly 2.2 秒（緩入緩出，兩端淡入淡出）；虛線流動 0.8 秒；翅膀 0.18 秒；停駐起伏 2.8 秒；取消收尾時 fly 4.4 秒、虛線 2.4 秒。
降級
系統「減少動態效果」或 設定 › 動效＝關：蜜蜂停在連線中點、虛線不流動；視窗隱藏或最小化時暫停（visibilitychange）。
可及性
動效 aria-hidden，純裝飾；狀態一律由 圖示 + 文字 + 顏色 表達。拓撲區塊以 role=img 與 aria-label 描述目前狀態。
效能
只用 transform、offset-distance、opacity 與背景位移，不觸發版面重排；動效開啟時閒置 CPU 增量目標 < 3%（待實測，列入驗收）。
系統匣
選單列／系統匣圖示不做逐格動畫（耗電），運行中只在圖示上加小圓點。
