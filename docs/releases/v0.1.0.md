# Loopbee v0.1.0

Loopbee 第一個公開版本。它是一個在你自己電腦上執行的桌面工具：把團隊已經在用的 Codex CLI 或 Claude Code 工作流程，變成可以定時執行、留下紀錄、在關鍵步驟停下來等人審核的「Loop」。程式、資料和 agent 都在本機，不需要雲端帳號或伺服器。

## 這個版本提供什麼

**用對話建立 Loop**
- 自動偵測本機的 Codex CLI 和 Claude Code，第一個找到的就是預設 agent，可在「設定 › Agent」切換。
- 在「新增 Loop」用一句話描述需求，例如「每個工作日 9 點，用我們的 fix-prod-errors skill 修線上錯誤，停在合併 master 之前通知我」。agent 會先唯讀地看過你的專案（AGENTS.md、CLAUDE.md、skills、腳本），再起草 Loop。
- 右側即時顯示流程圖、排程、權限和檢查結果；存檔後是停用的草稿，先手動跑一次再開排程。也可以改用表單編輯。

**本機工作流程與排程**
- 一個 Loop 由 Agent 任務、命令、驗證和人工關卡組成；驗證失敗可自動進入下一輪，並有輪數、時間上限和「無進展」停止條件。
- 排程使用 cron 加上你的時區；電腦睡眠錯過的排程可在醒來後補跑一次；相同資源鎖的 Loop 不會同時執行；可一鍵暫停全部排程。
- 每次 Run 可在全新的 git worktree 中進行，你自己的 checkout 和未提交的修改不會被動到。設定分支後，Loopbee 會建立分支並在每個 Agent 步驟後代為 commit；Loopbee 不會 push 或合併。
- 命令步驟可設定「失敗也繼續」，輸出會交給後面的 Agent 步驟，例如把失敗的測試寫進報告。

**執行紀錄與人工審核**
- 每個 Run 有逐步時間軸、命令輸出等證據檔，以及 Agent 的最終報告與結果：完成、無事可做、受阻。
- 人工關卡需要填寫審核備註才能核准或退回；在關卡等待的時間不算進時間上限，預設 72 小時沒人處理會自動結束。
- 「今日」頁彙整運行中、需要你處理的項目和今天的產物；可產生每日摘要。

**權限與安全**
- 四級權限：唯讀、可寫工作區、可寫加網路、沿用 agent 自己的設定；裝置有最高權限上限，調高需要再次確認。
- 環境變數可存放密鑰，密鑰放在系統鑰匙圈，Loop 定義只保存參照。

**通知、團隊與命令列**
- 每個 Loop 可選擇通知事件（完成、需要處理、失敗、無事可做）與通道：桌面通知、Telegram、飛書、Bark，可附上 Agent 報告。
- 可把公開的 Loop 定義與執行紀錄同步到團隊的 Git 儲存庫，私人 Loop 不會發布。
- `beectl` 命令列工具與 agent skill：執行 `beectl skill install` 後，可在 Codex 或 Claude Code 對話中直接建立 Loop 草稿。
- 介面支援繁體中文、簡體中文和英文，以及淺色和深色主題。

## 下載與安裝

| 平台 | 下載檔案 | 使用方式 |
|---|---|---|
| Windows 10/11 x64 | `Loopbee-windows-amd64.zip` | 解壓到固定的資料夾，執行 `loopbee.exe`。ZIP 內另有無介面版 `loopbee-nogui.exe` 和 `beectl.exe` |
| macOS Apple Silicon（M 系列） | `Loopbee-macos-arm64.zip` | 解壓後把 `Loopbee.app` 拖進「應用程式」 |

每個檔案旁的 `.sha256` 可用來校驗下載內容。

- **Windows**：需要 Microsoft Edge WebView2 Runtime（Windows 10/11 通常已內建）。關閉視窗後程式會留在系統匣繼續排程，從系統匣選單結束。資料在 `%APPDATA%\loopbee`。
- **macOS**：第一次開啟時，在 Finder 對 `Loopbee.app` 按右鍵選「打開」，或到「系統設定 › 隱私權與安全性」選「強制打開」。資料在 `~/Library/Application Support/loopbee`。
- **Agent**：請先安裝並登入 Codex CLI 或 Claude Code。Loopbee 會呼叫你本機的 CLI，使用你自己的訂閱額度。

## 已知限制

- 安裝檔沒有數位簽章，macOS 版也沒有經過 Apple 公證，第一次開啟會出現警告（處理方式見上方）。
- 電腦睡眠或闔上螢幕時不會執行任何排程。
- Claude Code 的沙箱不支援原生 Windows：在 Windows 上請使用 Codex，或讓 Claude Code 以唯讀或「沿用 agent 設定」權限執行。
- Codex 在沙箱內無法寫入 Git 內部檔案；需要 commit 的 Loop 請設定分支，由 Loopbee 代為 commit。
- 這一版只提供 Windows x64 和 macOS Apple Silicon。
