# loopbee v0.1.5

## 支援的 agent

- **不再支援 Gemini CLI**：支援的 agent CLI 現在是 Codex CLI、Claude Code、OpenCode 和 pi。把 Gemini CLI 設為預設 agent 的裝置，升級後預設 agent 會清空，改用第一個偵測到的 agent；使用 Gemini CLI 的 Loop 要在編輯器裡換一個 agent 才能執行。
## 新增功能

- **每個步驟選自己的模型與思考等級**：每個 Loop 和每個 agent 步驟都可以從 CLI 提供的清單選模型，並設定思考等級；步驟沒有設定時沿用 Loop，Loop 沒有設定時沿用 CLI 預設值。「設定 › Agents」會列出可用選項，Run 頁面會顯示各步驟使用的模型與思考等級。

- **多個 agent 分工，審查不通過就退回重做**：每個 agent 步驟可以用不同的 agent 和權限。新的「審查」步驟由 agent 檢查前面的成果，不通過時把意見退回指定的步驟重做，最多退回的次數可以設定（預設 3 次），超過就停下來等人處理。步驟可以勾選「交給這一步」，把前面步驟的報告交給它。審查不等於人工核准：之後的指令步驟仍然不會執行 agent 改過的檔案。

- **流程中途交付，可自動合併到測試分支**：新的「交付」步驟在流程中途推送分支、開 PR，之後的步驟（例如等待部署、QA 驗收）接著執行；QA 退回時會重新交付新的提交。「檢查通過後自動合併」模式只能合併到你指定的測試分支，不需要人工關卡；變更碰到你列出的路徑（例如 Kubernetes ConfigMap 的 YAML）時，會先停在人工關卡並列出這些檔案。預設分支永遠不會自動合併，`.github/` 的變更也不會自動推送。

- **流程圖**：編輯器、對話預覽和 Run 頁面用同一張流程圖。步驟會自動換列（手機上改成直式），審查會畫出退回到哪一步的虛線，並標出退回次數；每個節點顯示 agent · 模型 · 思考等級，執行時顯示第幾次嘗試、耗時和 token。點選節點可以看到每一次嘗試的報告和 diff；拓撲卡片列出這個 Loop 用到的每一個 agent。

- **用選的，不用打完整路徑**：桌面版裡，對話頁的「專案資料夾」、編輯器的「工作目錄」、「可讀路徑」和「複製到 worktree」旁邊都多了按鈕，會打開系統的選擇視窗。「複製到 worktree」只接受工作目錄裡的檔案或資料夾，會自動轉成相對路徑。在瀏覽器裡使用無介面版時沒有這個按鈕，照舊手動輸入。

## 修正問題

- 用對話建立 Loop 時，agent 較長的回覆會超出對話框，名字和內容也擠在同一列。現在回覆會完整顯示在對話框裡。
- agent 一次問兩個問題時，點第一個問題的答案就會立刻送出，第二個問題來不及回答。現在每個問題各選一個答案，全部選好後一起送出；也可以只選一部分，加上自己輸入的內容後按「送出」。
- 沒有填「專案資料夾」、只在對話裡提到資料夾時，草稿的工作目錄是空的，那個資料夾被放進「可讀路徑」。現在對話裡提到的資料夾（必須是存在的絕對路徑）會成為 Loop 的工作目錄，上方的「專案資料夾」欄位也會自動填上。
- 工作目錄是裝了多個倉庫的上層資料夾時，Run 會被擋下，只說「工作目錄必須是沒有未提交變更的 Git 倉庫」。現在錯誤會分清楚是「不是 Git 倉庫」還是「有未提交的修改」，並說明怎麼處理；用對話起草時，如果資料夾不是 Git 倉庫，也不會再開啟「要求乾淨的 Git 工作樹」。

## 下載與安裝

| 平台 | 下載檔案 | 使用方式 |
|---|---|---|
| Windows 10/11 x64 | `loopbee-windows-amd64.exe` | 直接執行桌面程式。建議先放到固定位置再開啟，因為「登入時啟動」和自動更新都會使用這個路徑 |
| Windows 10/11 x64 | `loopbee-windows-amd64.zip` | 可攜版：桌面程式 `loopbee.exe`、無介面版 `loopbee-nogui.exe` 和 `beectl.exe` |
| macOS Apple Silicon（M 系列） | `loopbee-macos-arm64.dmg` | 打開後把 loopbee 拖到「應用程式」 |
| macOS Apple Silicon（M 系列） | `loopbee-macos-arm64.zip` | 同一個 App 的壓縮檔，自動更新也是下載這個檔案 |
| macOS Intel | `loopbee-macos-amd64.dmg` | 打開後把 loopbee 拖到「應用程式」 |
| macOS Intel | `loopbee-macos-amd64.zip` | 同一個 App 的壓縮檔，自動更新也是下載這個檔案 |
| 全部 | `SHA256SUMS` | 所有下載檔案的校驗碼。用 `shasum -a 256 檔名`（macOS）或 `Get-FileHash 檔名`（Windows PowerShell）算出雜湊值，和這個檔案裡同名那一行比對 |

不確定 Mac 是哪一種晶片：點左上角蘋果選單 ›「關於這台 Mac」，「晶片」寫 Apple M 系列就下載 arm64，寫 Intel 就下載 amd64。

- **從 v0.1.2 到 v0.1.4 升級**：會自動更新，重新啟動或結束 loopbee 時安裝。
- **從 v0.1.1 或更早升級**：舊版沒有自動更新，請手動下載並覆蓋原本的程式；資料和存在系統鑰匙圈裡的 secret 都會沿用。
- **macOS**：App 還沒有 Apple 開發者簽章。第一次開啟時 macOS 會說「無法驗證 loopbee」，按「完成」，再到「系統設定 › 隱私權與安全性」，在下方按「強制打開」並輸入密碼；之後就能直接開啟。請從「應用程式」資料夾開啟：直接從「下載」或磁碟映像執行時，macOS 不允許 App 更新自己。資料在 `~/Library/Application Support/loopbee`。
- **Windows**：需要 Microsoft Edge WebView2 Runtime（Windows 10/11 通常已內建）。SmartScreen 出現警告時，按「其他資訊 › 仍要執行」。要自動更新，程式所在的資料夾必須是你能寫入的（例如不要放在 `C:\Program Files`）。資料在 `%APPDATA%\loopbee`。
- **Agent**：請先安裝並登入要使用的 agent CLI（Codex CLI、Claude Code、OpenCode 或 pi）。
