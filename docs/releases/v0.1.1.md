# Loopbee v0.1.1

這一版補齊了下載格式：Windows 可以直接下載執行檔，macOS 提供可拖曳安裝的 DMG，並新增 Intel Mac 版本。應用程式的功能與 v0.1.0 相同。

## 新增功能

- **Windows 執行檔**：新增 `Loopbee-windows-amd64.exe`，下載後可以直接啟動桌面程式，不需要先解壓。它不是安裝程式，不會建立捷徑或解除安裝項目。
- **macOS DMG**：新增 `Loopbee-macos-arm64.dmg`，打開後把 Loopbee 拖到「應用程式」即可安裝。原本的 ZIP 仍然保留。
- **支援 Intel Mac**：新增 `Loopbee-macos-amd64.dmg` 和 `Loopbee-macos-amd64.zip`，在 Intel 機器上原生建置並跑過測試。
- **統一的 `SHA256SUMS`**：一個檔案列出所有下載檔案的校驗碼，取代原本每個檔案各自的 `.sha256`。
- 程式內的版本號、macOS 的 App 版本和 Windows 的檔案版本，現在都和發布標籤一致。

## 下載與安裝

| 平台 | 下載檔案 | 使用方式 |
|---|---|---|
| Windows 10/11 x64 | `Loopbee-windows-amd64.exe` | 直接執行桌面程式。建議先放到固定位置再開啟，因為「登入時啟動」會記住這個路徑 |
| Windows 10/11 x64 | `Loopbee-windows-amd64.zip` | 可攜版：桌面程式 `loopbee.exe`、無介面版 `loopbee-nogui.exe` 和 `beectl.exe` |
| macOS Apple Silicon（M 系列） | `Loopbee-macos-arm64.dmg` | 打開後把 Loopbee 拖到「應用程式」 |
| macOS Apple Silicon（M 系列） | `Loopbee-macos-arm64.zip` | 同一個 App 的壓縮檔 |
| macOS Intel | `Loopbee-macos-amd64.dmg` | 打開後把 Loopbee 拖到「應用程式」 |
| macOS Intel | `Loopbee-macos-amd64.zip` | 同一個 App 的壓縮檔 |
| 全部 | `SHA256SUMS` | 所有下載檔案的校驗碼。用 `shasum -a 256 檔名`（macOS）或 `Get-FileHash 檔名`（Windows PowerShell）算出雜湊值，和這個檔案裡同名那一行比對 |

不確定 Mac 是哪一種晶片：點左上角蘋果選單 ›「關於這台 Mac」，「晶片」寫 Apple M 系列就下載 arm64，寫 Intel 就下載 amd64。

- **Windows**：需要 Microsoft Edge WebView2 Runtime（Windows 10/11 通常已內建）。若要使用 `beectl`，請下載 ZIP。資料在 `%APPDATA%\loopbee`，從 v0.1.0 升級會沿用原有資料。
- **macOS**：第一次開啟時，在 Finder 對 `Loopbee.app` 按右鍵選「打開」，或到「系統設定 › 隱私權與安全性」選「強制打開」。資料在 `~/Library/Application Support/loopbee`，升級會沿用原有資料。
- **Agent**：請先安裝並登入 Codex CLI 或 Claude Code。

## 已知限制

- 安裝檔沒有數位簽章，macOS 版也沒有經過 Apple 公證，第一次開啟會出現警告。
- Windows 版沒有安裝精靈、開始選單捷徑和解除安裝功能；需要的話會另外提供 Setup 安裝程式。
- 尚未提供 Windows ARM64 和 Linux 桌面版。
- 電腦睡眠時不會執行排程；Claude Code 的沙箱不支援原生 Windows（詳見 v0.1.0 說明）。
